# USACO Bronze Visualizer

An interactive web-based visualizer for USACO (USA Computing Olympiad) Bronze level algorithms. This tool helps students learn competitive programming concepts through visual animations and step-by-step execution.

## Features

🎯 **Multiple Algorithm Visualizations**
- **Simulation**: Watch objects move and interact in real-time
- **Sorting**: See bubble sort in action with comparisons and swaps highlighted
- **Grid Traversal**: Visualize flood fill algorithm on 2D grids
- **Array Manipulation**: Track array transformations step-by-step

🎮 **Interactive Controls**
- Play, pause, and step through algorithms
- Adjustable animation speed
- Reset to initial state
- Custom input support

📊 **Real-time Statistics**
- Step counter
- Comparison counter (for sorting)
- Swap counter (for sorting)

🎨 **Modern UI**
- Responsive design for all devices
- Clean, intuitive interface
- Color-coded visualizations
- Sample USACO Bronze problems included

## Getting Started

### Quick Start

1. Open `index.html` in a web browser
2. Select a problem type from the buttons
3. Click "Play" to watch the visualization
4. Use "Step" for detailed analysis
5. Try custom inputs or sample problems

### Using Custom Input

For **Sorting** and **Array** problems:
```
5 2 8 1 9 3
```

For **Grid** problems:
```
3 3
...
#.#
...
```

### Sample Problems

The visualizer includes three classic USACO Bronze problems:
- **The Cow Signal** (2016 December)
- **Milk Pails** (2016 February)  
- **The Lost Cow** (2017 US Open)

## Educational Use

This visualizer is designed to help students:
- Understand algorithm execution step-by-step
- Visualize data structure changes
- Learn common USACO Bronze patterns
- Debug their solutions by comparison
